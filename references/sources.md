# 数据源（2026-09-29 实测修订）

## 核心接口：东财数据中心龙虎榜

```
https://datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_DAILYBILLBOARD_DETAILSNEW&source=WEB&client=WEB&columns=ALL&filter=(TRADE_DATE='2026-09-28')
```

- 请求时带桌面端 UA；服务端直连可通，无需 Referer（2026-09-29 实测一次调通）。
- **`columns=ALL` 必带**：不带则返回 `{"success":false,"code":9501,"message":"返回字段参数不能为空"}`。
- **filter 日期格式**：`TRADE_DATE='YYYY-MM-DD'`（日期部分即可；字段实际返回 `YYYY-MM-DD 00:00:00`，filter 用日期部分匹配成功）。
- 分页：`pageSize` / `pageNumber`；单日上榜约 60-80 条，一次 `pageSize=200` 取全（2026-09-28 实测 67 条、1 页）。

### 关键字段（2026-09-28 实测口径）

| 字段 | 含义 | 口径 |
|---|---|---|
| `BILLBOARD_NET_AMT` | 净买额（元） | = `BILLBOARD_BUY_AMT` − `BILLBOARD_SELL_AMT`，实测精确成立；Top5 排序依据 |
| `BILLBOARD_BUY_AMT` | 龙虎榜买入额（元） | 上榜席位买入合计 |
| `BILLBOARD_SELL_AMT` | 龙虎榜卖出额（元） | 上榜席位卖出合计 |
| `EXPLAIN` | 席位标签（标签级） | 如"3家机构买入，成功率50.45%"、"浙江资金买入，成功率48.10%"、"买一主买，成功率42.63%" |
| `EXPLANATION` | 上榜原因 | 如"日涨幅偏离值达到7%的前5只证券"、"日换手率达到20%的前5只证券" |
| `SECURITY_CODE` / `SECURITY_NAME_ABBR` | 代码 / 简称 | 000513 / 丽珠集团 |
| `CHANGE_RATE` / `TURNOVERRATE` | 涨跌幅% / 换手率% | 当日收盘口径 |
| `BUY_SEAT` / `SELL_SEAT` | 席位计数（占位码） | 实测为"11111"占位值，**不代表具体营业部** |

### 接口局限（必须写入解读规则）

1. **公共接口不返回营业部席位明细**：只能到 EXPLAIN 标签级（如"1家机构买入"）。看到"西藏自治区资金""浙江资金"等地域标签时，只能原样引用标签，**绝不写成具体营业部**（如拉萨某营业部）。
2. **EXPLAIN 标签方向 ≠ 净买额方向**：标签描述的是席位类型归因，不是资金方向。实测：超声电子（000823）净买入 +3.8 亿，标签却是"2家机构卖出"；我爱我家（000560）净卖出 −1.9 亿，标签是"3家机构买入"。分类时只按席位类型归类，不按标签字面"买入/卖出"推导。
3. **"成功率"是标签自带字段**：如"成功率48.10%"，为东财对席位历史胜率的统计，原样引用，不解释算法。
4. 深沪股通专用席位：2026-09-28 数据中未出现（股通相关标签 0 条）；出现时标签含"股通"字样，届时单独成类。
